# 🦠 COVID-19 Image Recognition using CNN

This project uses **Deep Learning and CNN (Convolutional Neural Networks)** to classify chest X-ray images into **COVID-19, Pneumonia, and Normal** classes.

## 🎯 Objective

To build CNN models, evaluate their performance, and compare the models to identify the better-performing model.

## 🛠️ Technologies Used

* Python
* TensorFlow / Keras
* NumPy
* Pandas
* Matplotlib
* Jupyter Notebook

## 🔍 Project Workflow

1. Load and preprocess the image data
2. Prepare the data for training
3. Build CNN models
4. Train the models
5. Evaluate model performance
6. Compare the CNN models

## 📊 Results

The models were evaluated using **accuracy and recall** on training and validation data. The model comparison helped identify the better-performing CNN architecture.

## 📂 Dataset Files

* `CovidImages.npy` – Chest X-ray images
* `CovidLabels.csv` – Corresponding labels
* `Covid_19_image_Recognition.ipynb` – Complete implementation

## 💡 Key Learning

This project helped me gain practical experience in **CNN, image classification, data preprocessing, model evaluation, and Deep Learning**.
